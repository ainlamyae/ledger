# Documentation

[README](../README.md) › Docs

Every Ledger doc, grouped by what you need: using a page, looking up a fact, or working on the code.

## At a glance

- **Guide:** what each page shows and does, for anyone using the app.
- **Reference:** sheet tabs, formulas, names and visual rules to look things up in.
- **Development:** setup, architecture, data access, security and releases.
- **Changelog:** every commit with the version it produced.
